# dr-gero-dist

Ficheros de distribución de una extensión de navegador interna: el paquete
firmado (`.crx`) y el manifiesto de actualización que consume Chrome.

Nota: un `.crx` es un zip firmado, no un binario compilado — su contenido
(incluido el código JavaScript) es legible por cualquiera que lo descargue
y lo descomprima. Este repositorio no oculta código, solo distribuye el
paquete instalable. El repositorio con el historial de desarrollo, tests
y documentación es privado y no vive aquí.
